# 更新记录 (Changelog)

> 版本按时间倒序。每条都记录了「现象 → 原因 → 修法」，方便对照自己的版本判断行为是否正常。

### v0.1.10（2026-10-09，全新图标 + 桌面快捷方式规范化）

**改动：换掉用了九个版本的旧图标，并统一桌面入口。**

- 图标重做。旧图标是紫渐变方块 + llama + "Uncensored" 字样，与本程序（选课工具）毫无关系，
  而且和另外两个本机工具共用同一个 .ico 文件。
- 新图标沿用一套自定视觉语言：**深色底 `#0D0F12` + 白色几何主体 + 单一选择性着色**（运行态绿 `#3DDC84`）。
  图形是「左侧竖轴 + 三条课程条 + 右上绿色对勾」——竖轴是课程列表、对勾是"已选上"，
  正好对应本程序做的事（从课表里挑课）。
- 图形按 **16px 可辨识** 这个硬指标设计：细线条在小尺寸会糊，所以竖轴与横条都做了加粗，
  勾收敛在条的右上区、不越界。
- 生成方式：**手写 ICO 编码器**输出传统 BMP/DIB 帧。
  原因：Pillow 保存 ICO 时会写成 PNG 压缩帧，而 Tkinter 的 `iconbitmap()` 只接受 BMP 帧，
  用了 PNG 帧会**静默不显示**（不报错，图标就是不出现）。多尺寸 16/24/32/48/64/128/256 全带。
- 覆盖三个位置：桌面快捷方式、窗口左上角（标题栏）、任务栏。
  窗口图标经实测校验：标题栏 32px 图标与源文件相关度 **+1.000**，16px 小图标 **+0.978**。
- 桌面快捷方式改名为 `工商大学选课助手 v0.1.10`，描述补上作者署名。

**注意**：老版本的 `v0.1` 运行目录保留未删，如果新版有问题可以直接回到它。

**顺带修掉一个老 bug（免安装版专属）**：打包成 exe 后窗口图标会退回 **Python 默认的羽毛图标**。

- 原因：程序用 `Path(__file__).resolve().parent / "zjgsu_launcher.ico"` 找图标文件，
  而 PyInstaller 打包后 `__file__` 指向**解包临时目录**，里面并没有这个 .ico；
  读取失败又被 `except Exception: pass` 静默吞掉，于是 Tk 用了默认图标——
  **这个毛病 v0.1.9 及更早的免安装版一直都有**（只是没人盯着标题栏看）。
- 修法：新增 `_icon_path()`，按「打包目录 → exe 所在目录 → 源码目录」逐个位置查找，
  找到即用；打包命令也补上 `--add-data "zjgsu_launcher.ico;."` 做双保险。
- 实测校验：修复后 exe 窗口的 32px 图标与源文件相关度 **+1.000**（修复前是 Python 羽毛图标）。

### v0.1.9（2026-09-17，已选列表不再重复 + 「自动对齐已选」进度不再闷声不响）

**问题 1：「已选课程」里出现两条"中国城市经济与发展"。**

- 教务已选那条的教学班名是 `(2026-2027-1)-GENEML053-01`；
  本程序抢到的记录里是 `国情课(2026-2027-1)-GENEML053-01`（多一个课程别名前缀）。
- 以前去重比的是**整串**教学班名 → 同一个班被当成两门课，列表里出现两条，
  通识进度也会被多算一门。
- 修法：新增 `teaching_class_core()`，统一按**核心教学班号**（学期+课程号+班号）比。
  校区前缀（教工路…）、网课平台前缀（智慧树网络课…）、课程别名前缀（国情课/影视鉴赏…）
  一概忽略；**班号不同仍是两个班**，不会误合并。
- 连带修：课程库（`course_catalog.json`）里只存了其中一种写法，以前按整串查详情会取不到，
  导致"中国城市经济与发展"被归到"主修"、通识进度显示 1/2（真值 2/2）。
  现在 `catalog_entry()` 带前缀/不带前缀都能查到详情。
- 同一处前缀坑也修了「待选 → 已选」的对账（`reconcile_system_selected` /
  `reconcile_completed_pending`）：待选里写的是带前缀的名字时，也能正确识别"教务已经选上了"。

**问题 2：「每 60 秒读一次已选课程」的功能好像没了。**

- 功能没坏，**定时器一直在跑**（实测 7 秒内被触发、有 Cookie 时正常刷新）。
  真实原因：重启软件后 Cookie 框是空的，`maybe_auto_refresh` 遇到空 Cookie 直接静默返回，
  既不刷新也不说为什么，日志里从此再没有「已选课程刷新完成」——看起来就像功能被删了。
- 修法：把"为什么没在刷新"如实写出来 ——
  - 界面提示行变成：`已选数据：尚未刷新（自动对齐中·缺 Cookie，点一下「抓取 Cookie」就开始，每 60 秒）`
  - 日志里说明一次（同一条原因只记一次，不刷屏）：`自动对齐已选：暂时跳过（缺 Cookie…）`
  - 开关按钮文字统一成「自动对齐已选（每60秒）」，不再一处带间隔一处不带。
- ⚠ 使用提醒：**每次重启软件都要重新点一次「抓取 Cookie」**，否则自动对齐只是空转（以前它不吭声）。

### v0.1.8（2026-09-17，搜索抢课整页可滑动 + 「更多筛选」折叠）

**问题**：搜索抢课这一页内容比 Notebook 高得多 —— 实测 1920x1040（你平时最大化的尺寸）下
**结果表格只剩 1px 高**，等于看不见；1120 窗口下筛选区还会被横向压扁
（「创新、创意、创业」按钮只剩 35px 宽）。

**修法（按你的要求：让整个页面整体滑动）**：

1. **整页滑动**：搜索行固定在顶部不动，其余（筛选区 + 循环抢课 + 勾选工具行 + 结果表格）
   整块装进一个可滚动页面。页面不够高就整体上下滑，表格拿回自己的完整高度
   （10 行 ≈ 491px，实测滚到底能完整看到），不再被筛选区挤成 1px。
   窗口够高时滚动条自动收起（1600x1800 实测：不出现滚动条，表格 694px）。
2. **滚轮归属**：指针在结果表格上、且表格自己还有内容可滚 → 滚表格；否则滚整页；
   指针在别的 Tab（待选列表/课表）→ 原样放行，各滚各的。
3. **「更多筛选」折叠**：课程归属（通识细分）+ 课程组两行收进折叠区，默认收起；
   里面有启用中的条件时**自动摊开**，按钮上始终写着「已启用 N 项」——
   不会出现"看不见的筛选条件把课程悄悄过滤掉"。状态记在设置里，下次打开还在。
4. 顺手修掉一个老毛病：表格行高以前用 `minsize` 硬顶，Tk 的 grid 在空间不够时会**把行撑出容器**
   （表格底部被裁、数字却显示得挺大）。现在表格行数按实际剩余空间算，不再溢出。

### v0.1.7（2026-09-17，抢课循环有了"收工条件"：没得抢就不再空转）

**问题**：抢课监控在"一个志愿都提交不了"的时候不会停 —— 转了一整晚。

现场（2026-09-17 日志与数据）：教务已选里通识已经 **2 门**（名额上限就是 2），
而待选里 18 个志愿**全是通识** → 每一轮每一门都被「通识名额已达到 2 门，跳过后续保底」跳过，
一次提交都没发出去，界面也早就写着"✓ 选课已完成"，但循环一直在跑
（日志实测：48 秒刷了 110 轮"第 N 轮"，一分钟一条 init + 已选刷新）。

**原因**：循环的退出条件只有四个 —— 点「停止」、最大轮次、最多选 N 门（默认 0 = 不限）、
以及**抢到之后**才检查"目标是否全部完成"。**"一个都抢不了"这种情形没有任何退出条件**，
所以哪怕毫无动作也会一直空转。

**修法**（`monitor_rush`，三轮判断）：

1. **每轮开抢前先看有没有得抢**：全量志愿里没有任何一门值得提交（名额满 / 已完成 /
   与教务已选重复）→ 直接收工，**一次网络请求都不发**，日志写明原因：
   `没有可提交的志愿了（通识名额已满（2/2）、已完成 2 门志愿）—— 任务结束，抢课监控自动停止，不再空转。`
2. **本轮一次提交都没发出去时再判一次**：涵盖"抢到最后一门之后"和"志愿全是教务已选那门课的另一个班"
   （这种情况提交也没意义，教务会把先选上的替换掉）。
3. **启动时先写一行名额基数**：`类别名额基数（教务已选 + 本程序抢到）：通识 2/2，英语 1/1，体育 1/1`
   —— 事后翻日志一眼就能看出"当时是不是已经没名额了"。

**不会误伤的情形**（都有回归测试守着）：满课蹲守（容量已满，继续盲打退课空位）、
时间冲突这类硬失败（继续重试）、主修课程等**没有名额上限**的志愿（通识满了照样抢）。

⚠ 两点使用提醒：

- 监控"收工"= 这一轮没有可提交的志愿了。**如果之后教务那边掉课**（志愿没中/被退），
  已选刷新会把课放回待选列表，此时需要**重新点一次「开始监控」**（不会再自动接上）。
- 「自动对齐已选（每60秒）」是另一个独立开关，只做只读查询，与抢课循环无关；
  不想让它每分钟查一次，在界面上关掉即可。

   注意：为了让新增的列不把表格撑更宽，其余列各让出几个像素，整表列宽总和反而**比 v0.1.5 略窄**。
2. **新增「学分筛选」**（搜索抢课 Tab 筛选区，「周数筛选」下面一行）：按钮按你课程数据里
   **实际出现过的学分**动态生成（`0/0.5/1/1.5/2/3/4/5/6/8` 分），不会出现点了永远搜不到的死按钮。
   - 通识选修课只有 **1 分 / 2 分**两档（实测 181 条 1 分、109 条 2 分），挑通识时点「1分」「2分」即可。

   - 学分取不到的课在启用学分筛选时一并排除，状态栏照例写明「另有 N 个被「学分=… 分」筛掉

3. **勾选更醒目**：「选」那一列从 36px 收窄到 26px，但**勾选的行会整行变绿加粗**，

### v0.1.5（2026-09-16，搜索抢课·周数筛选 + 筛选区标签补全）

1. **新增「周数筛选」**（搜索抢课 Tab 筛选区，「上课节次」下面一行）：教务的课常常只上其中几周
   （`{8-13周}`），同一时间段但周次不重叠的两门课其实并不撞车，所以单独加一个按周次收窄的条件。
   - 「模式：只留含于」（默认）—— 只保留上课周次**全部落在**你输入区间内的课。
     例：输入 `1-7` → 留下 `1-3`、`2-7`、`1-7`；`1-16`（超集）、`6-9`（超出）被排除。
   - 「模式：剔除重叠」（点按钮切换）—— 去掉任何一段与输入区间**有重叠周次**的课。
     例：输入 `8-13` → 留 `1-7`、`14-16`；`7-13`、`13-16`、`8-13` 全部排除。
   - 输入格式：`1-7`、`8-13`、`1-7,14-16`（逗号/空格/顿号分隔，带不带「周」都行，支持 `(单)`/`(双)` 单双周，
     `1-16周(双)` 只算 2、4、…、16 周）。回车（或点走输入框）生效，「清空」一键去掉条件。
   - 一个教学班有多段（前半学期 / 后半学期）时，**每一段都要满足**条件才留下。
   - 上课时间识别不出来的课（教务里时间字段是 `--` 的网课 / 时间待定）**两种模式都会被排除**，
     状态栏会写明「另有 N 个被「周数含于=8-13」筛掉（含时间/周次识别不出的）」，避免以为搜索坏了。
   - 条件存在设置里，重启还在。
   - ⚠ **这只帮你看和挑，不改变提交口径**：提交时教务的冲突判定是**按节次、不看周次**的
     （实测 `逻辑学导论{8-12周}` 与 `美国法律文化{1-5周}` 同节次仍被教务判「上课时间冲突」），
     所以"周次不重叠"不等于教务一定放行。
2. **筛选区被裁掉的文字补全**：「课程归属（通识属性）」原来标签列写死 10 个字符宽（中文占 2 个），
   只显示成「课程归属（通」，现在折成两行「课程归属 / （通识）」完整显示。
   没有靠加宽标签列来解决：这一行自己就有 7 个按钮，列一宽右边的按钮就被挤出可见区
   （实测默认 1120 窗口下「创新、创意、创业」「其它」会看不见），所以选择折行、列宽不变。

### v0.1.4（2026-09-15 晚，抢课节奏旋钮 + 教学班名前缀分类修正）

1. **删掉骗人的「并行抢课」开关**：它在抢课循环里本来就被无条件关掉（并发提交会让
   "到底哪一门成功了"记不清账），留着只会让人以为点了就变快。提交仍然串行——正方选课接口
   是会话绑定的写操作，并发会撞"频率过高"、结果归属也判不准；真正能并行的是只读查询
   （「拉取全部课程」已经是 8 线程，2709 条 13 秒）。
2. **新增「优先盯前N门」**（0 = 盯全部）：门数一多，每一轮光排队就要几分钟，绝大部分时间
   都花在"确认那些课还是满的"。填一个 N 后，只高频盯列表最前面的 N 门，其余保底**每 3 轮试一次**；
   前 N 门全部到手后自动恢复全量，让保底顶上来。日志每轮会写明本轮范围。
3. **新增「满课节流(秒)」**：满课盲打的间隔（默认 2.5 秒，允许 0.5~10）。调小更激进、更容易抢到
   退课空位，但更可能被教务判「频率过高」；之前这个值是写死的。
4. **教学班名前缀分类修正**（重要）：教务在教学班名前加的前缀其实有**三种**，之前只区分了两种：
   - 校区（`教工路(...)`）—— 跨校区通勤，标 ⚠ 并可按校区筛；
   - 网课平台（`智慧树网络课(...)`/`尔雅网络课(...)`）—— 显示为「网课」，不算异地；
   - **课程别名**（`影视鉴赏(...)`/`美术鉴赏(...)`/`音乐鉴赏(...)`…）—— 既不是校区也不是网课。
   修正了两个错：① 别名不再被标成「网课」（那是假信息）；② **`教工路美术鉴赏(...)`/`教工路创新研讨(...)`
   这种校区名和别名连写的前缀，现在能正确识别成教工路**（之前会漏掉，等于放一门要跨校区通勤的课进来）。
   实测你的缓存：教工路教学班从 32 条变 **34 条**（多认出 2 条），网课 11 条（全部是真网课，无误标）。
5. **同一门课只押一个班**（对应你说的"一个课程分成两个时间，可能实际是同一课程"）：
   列表里 `食品营养学 GENNET030-3` 和 `GENNET030-1` 是同一门课的两个班（一个 1-6 周、
   一个 8-13 周，截图里那种"两个时间"其实就是前后半学期）。现在按**课程号**去重：
   - 分配时间段时，同一门课只允许第一条成为"已分配"，其余自动降为"备用"，理由会写明
     "与第 N 条同课程（GENNET030），同一门课只押一个班"；
   - 开抢时把「教务已选 + 本程序已抢到」的课程号一起计入去重，命中就跳过并记
     "同课程已在教务/已完成（GENNET030），跳过另一个班"——**跨重启也有效**。
     这一步很关键：教务对同一课程选两个班通常是把先选上的**替换掉**（等于拿一次机会换了个更差的班）。
6. 两个新旋钮的状态会保存在设置里，下次打开还在。

### v0.1.3（2026-09-15，搜索抢课批量勾选 + 校区识别）

1. **搜索抢课支持勾选多行、批量操作**：
   - 结果表第一列是「选」方框（点一下勾上/取消），支持一次勾多行；
   - 三种全选入口：工具行「☑ 全选」、「清空勾选」、「⇄ 反选」，表头点「选」一键全选/全清，或按 `Ctrl+A`；
   - 「加入勾选到抢课」按勾选**批量加入**（每行锁定各自的教学班、详情一起写入）；
   - 「一键抢课（勾选行）」按勾选**批量提交**（整批共用一个连接，只登录一次）；
     勾了「循环抢课」时会在多轮之间反复重试未成功的那些班，直到全部成功或被停止；
   - 一行都没勾时，退回"高亮选中的那一行"，两种习惯都能用。
2. **教工路校区自动识别 + 标注 + 筛选**（我是下沙的学生）：

   - 加入教工路课程时会**弹窗警告**（跨校区通勤），日志也留痕。
